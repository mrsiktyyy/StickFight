STICKSFIGHT — аккаунты и комнаты

1) Supabase → Authentication → Sign In / Providers:
   - Email: Confirm email выключен.
   - Anonymous Sign-Ins: включить (нужно для гостевого режима).
2) Supabase → SQL Editor → New query:
   - вставить весь файл supabase_setup.sql и нажать Run.
3) Supabase → Project Settings → API:
   - в проекте уже используется URL и Publishable Key, которые были переданы.
4) Загрузить index.html в GitHub вместо старого файла или заменить файлы проекта в Vercel.
5) После деплоя открыть сайт в новой вкладке.

Функции:
- Вход/регистрация по нику и паролю.
- Гостевая сессия (ник «Гость»).
- Гость может создавать комнаты и входить в комнаты.
- Постоянный аккаунт может менять ник и аватар.
- Комнаты отображаются у всех подключённых пользователей через Supabase Realtime.

Важно:
Это первый рабочий этап онлайн-лобби. Для полноценного соревновательного матча надо следующим этапом перенести проверку каждого хода в серверную RPC-функцию, добавить защиту от подмены состояния, обработку переподключения, завершение комнаты и запись статистики. Не выдавать этот пакет за завершённый античит/соревновательный сервер.
